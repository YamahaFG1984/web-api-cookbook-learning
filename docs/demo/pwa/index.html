离线演示应用

这个页面注册了一个 Service Worker（sw.js），它只控制 demo/pwa/ 目录。 按下面的步骤体验「断网也能打开」的网页。

🔑 体验步骤
  1. 打开本页后稍等片刻，确认下方「当前页面是否被控制」显示为「是」（sw.js 在 activate 时调用了 clients.claim()，所以首次打开就会被接管；如果显示「否」，刷新一次即可）。
  2. 打开开发者工具 → Network（网络）面板 → 把「No throttling」改为 Offline（离线）。
  3. 再刷新页面：页面照常显示，样式也在 —— 它们来自缓存。
  4. 在离线状态下访问 一个没有缓存过的页面，会看到 Service Worker 返回的离线提示页。
  5. 开发者工具 → Application（应用）→ Service Workers / Cache Storage 中可以看到它的状态和缓存。

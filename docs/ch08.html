第 8 章

Web Animations API

第 1 章用 requestAnimationFrame 手写了一个淡出动画：要记时间戳、算每帧的增量，代码不短。 CSS 动画写起来简单，却难以用 JS 精细控制。Web Animations API（简称 WAAPI）把两者的优点合在一起： 用关键帧描述动画，用 JS 对象控制播放。

本章目标

  • 用 element.animate(keyframes, options) 创建动画，理解 Animation 对象
  • 控制播放：暂停、继续、反向、取消，以及用 finished Promise 编排动画顺序
  • 理解填充模式（fill）、缓动函数（easing）、合成模式（composite）
  • 做出水波纹、入场退场、弹跳、加载动画、滚动进度条
  • 尊重用户的「减弱动态效果」设置

8.1点击时的「水波纹」效果

点击按钮时，从点击的位置扩散出一圈水波纹（Material Design 风格）。

试一试：在按钮的不同位置点击，也可以快速连点

每次点击时临时创建一个圆形元素，把它的中心放在点击位置，然后放大并淡出，结束后删掉：

  • 绝对定位的参照物：position: absolute 的元素，相对于最近的「已定位」祖先（position 不是默认的 static）来定位。所以按钮要设 position: relative。
  • 为什么要 pointer-events: none：如果点在正在扩散的波纹上，event.offsetX/Y 会以波纹为参照计算，新波纹的位置就错了。忽略指针事件后，点击直接落到按钮上。
  • 连续点击：每次点击都有自己的波纹元素和自己的动画，互不干扰。用纯 CSS 动画很难做到这点。

ⓘ 默认值不一样！

CSS animation / transition 的默认缓动是 ease，而 WAAPI 的默认是 linear。 直接把 CSS 动画「翻译」成 animate() 时，记得显式写上 easing。 经验法则：进场用 ease-out（快速出现、柔和停下），退场用 ease-in。 还可以写 cubic-bezier(…) 自定义，或用 linear(…) 函数描述弹簧效果（Baseline 2023）。

✨ 纯 CSS 的入场 / 退场：@starting-style

CSS 过渡以前有两个老大难：元素刚插入时没有「起始样式」可以过渡；display: none 不能过渡。现在两者都有了解法： @starting-style 定义入场的起点 Baseline 2024， transition-behavior: allow-discrete 让 display 等离散属性参与过渡。第 13 章的对话框和弹出层会用到它们。

8.6让元素弹跳

让一个元素短暂地弹跳几下，像受重力影响一样越弹越低。

  • 动态关键帧：每次循环用不同的 distance，这是 CSS @keyframes 做不到的。
  • offset 指定关键帧出现在动画的哪个时间点（0 到 1）。不写时，关键帧会在时间上均匀分布。
  • 为什么用 for...of 而不是 forEach：forEach 不会等待回调里的 await，三段动画会几乎同时开始，只能看到最后一段。for...of（或普通 for 循环）会老老实实地等。

8.9尊重用户的动画偏好

用户在操作系统里开启了「减弱动态效果」，你的动画应该收敛或关闭。

这对无障碍极其重要：大幅度或快速的运动可能让前庭障碍用户头晕恶心，甚至诱发癫痫或偏头痛。 「减少」不等于「全部关掉」：可以把弹跳换成简单的淡入，把大范围位移换成透明度变化。

💡 封装一个统一的入口

CSS 里同样可以用 @media (prefers-reduced-motion: reduce) { … } 关闭过渡。

小结

  • element.animate(keyframes, options) 返回 Animation 对象，可以 play / pause / reverse / cancel / finish，并用 finished Promise 等待结束。
  • 优先对 transform 和 opacity 做动画；WAAPI 默认缓动是 linear。
  • fill 决定动画前后的样式；forwards 之后可以 commitStyles() + cancel() 收尾。
  • 多个 transform 动画用 composite: 'add' 叠加，或改用独立的 translate / rotate / scale 属性。
  • ScrollTimeline 让动画跟随滚动，使用前做特性检测；CSS 的 animation-timeline 是同一能力的声明式版本。
  • 始终检查 prefers-reduced-motion。

第 11 章

国际化（Intl）

同一个日期，美国人写 6/2/25，德国人写 2.6.25，中国人写 2025/6/2； 同一个数字，英文写 5,200.55，德文写 5.200,55。 浏览器内置的 Intl 对象掌握着全世界几百种语言和地区的格式规则，以前要靠 Moment.js、Numeral.js 做的事，今天大多一行原生代码就能完成。

本章目标

  • 理解「区域设置」（locale）标签的组成，知道如何获取用户的语言
  • 格式化日期、相对时间、数字、货币、单位、价格区间
  • 用 PluralRules 处理单复数，用 ListFormat 拼接列表，用 Collator 排序
  • 用 Segmenter 正确地统计字、词、句 —— 包括中文分词
  • 了解 DurationFormat、DisplayNames 和新的 Temporal 日期 API

区域设置（locale）

几乎所有 Intl API 的第一个参数都是 locale：一个 BCP 47 语言标签，通常由「语言 + 地区」组成， 例如 en-US（美国英语）、en-GB（英国英语）、zh-CN（中国大陆简体中文）、zh-TW（台湾繁体中文）。 它还可以带上更多信息：

11.5保留小数位

把一个小数四舍五入到指定的小数位数再显示。

ⓘ maximum 与 minimum

maximumFractionDigits: 2 表示「最多两位」，所以 5.50 显示为 5.5。 要固定显示两位（例如金额），同时设置 minimumFractionDigits: 2。 与 number.toFixed(2) 相比，Intl 的结果带有本地化的千位分隔符和小数点。 另外，roundingMode 选项（如 'floor'、'halfEven'）可以控制舍入方式。Baseline 2023

11.6格式化价格区间

给定一组价格，显示为「最低价–最高价」的货币区间。

ⓘ 货币由你决定，格式由 locale 决定

currency 是「钱是什么币种」（业务数据），locale 是「用谁的习惯写」（用户偏好），两者相互独立。 new Intl.NumberFormat('zh-CN', { style: 'currency', currency: 'CNY' }).format(1234.5) 得到 ¥1,234.50； 日元没有小数，JPY 会自动四舍五入到整数。

⚠ 词数被高估了：要过滤 isWordLike

按 word 切分时，空格和标点也会成为独立的片段。对 "Hello, world!"，原书的写法会数出 5 个「词」（Hello / , / 空格 / world / !）。 每个片段都有一个 isWordLike 属性，只数它为 true 的：

你可能以前用 text.split(' ') 统计单词，用 text.length 统计字符。这两种做法在很多语言里都是错的： 中文、日文、泰文没有空格分词；emoji 和带声调的字符会被 length 数成多个 UTF-16 码元。 Segmenter 按照该语言的真实规则切分。Baseline 2024（书写作时 Firefox 尚不支持，现已全面可用）

把数组显示成符合语言习惯的列表，如「user1, user2, and user3」。

英语有「牛津逗号」（and 前面的逗号），德语没有；中文用顿号「、」。array.join(', ') 处理不了这些差异。 设置 { type: 'disjunction' } 可以得到「或」的列表：A、B或C。

11.11对姓名数组排序

按照语言规则对一组姓名排序。

compare(a, b) 返回负数表示 a 在前、0 表示相等、正数表示 a 在后（不一定正好是 -1 或 1）。 为什么不直接用 sort()？因为默认排序比较的是 UTF-16 码元，大写字母全排在小写前面，带重音的字母被扔到最后：

两者背后是同一套算法。区别在于：localeCompare 每次调用都要重新准备排序规则， 排序大数组时，预先创建一个 Collator 反复使用快得多。

小结

  • Intl API 以 locale 为输入：navigator.language 获取用户语言；不传则用浏览器默认值。
  • DateTimeFormat（dateStyle / timeStyle / timeZone）、formatToParts 分段；RelativeTimeFormat 只负责翻译「数值 + 单位」，差值要自己算。
  • NumberFormat 一个对象搞定数字、货币、百分比、单位、紧凑写法和区间。
  • PluralRules 返回类别名，文案按类别准备；ListFormat 处理连接词；Collator 负责排序并支持数字排序。
  • Segmenter 按语言规则切分字、词、句，统计词数时过滤 isWordLike。
  • 格式器对象创建一次反复使用；新项目可以关注 DurationFormat 与 Temporal。

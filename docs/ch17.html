CSS 相关 API

CSS 不只是写在样式表里的规则。浏览器还开放了一组 API，让 JavaScript 能够：给任意文字范围加高亮而不改动 DOM、 掌控字体何时加载完成、给页面切换加上动画、在运行时修改样式表、查询媒体条件，以及读取元素最终生效的样式。

本章目标

  • 用 Range + CSS Custom Highlight API 高亮文字

  • 用 View Transitions API 给 DOM 变化加过渡动画
  • 在运行时插入 CSS 规则、按条件切换 class、响应媒体查询变化
  • 分清 element.style 与 getComputedStyle

17.4在运行时修改样式表

你想在页面运行时动态添加一条 CSS 规则。

比如单页应用动态加入了新内容，可以同时加入它需要的样式规则。

⚠ 三个注意点
  • insertRule(rule, index) 的第二个参数默认为 0，新规则插在样式表的最前面，优先级相同时会被后面的规则覆盖。想放在最后：insertRule(rule, sheet.cssRules.length)。
  • 来自其他域名的样式表（如 CDN 上的 CSS）不允许读取和修改 cssRules，会抛出 SecurityError。
  • 一次只能插入一条规则。
✨ 更好的选择：CSS 变量与可构造样式表

classList.toggle('a')有就删，没有就加；返回切换后是否存在

17.7获取元素的计算样式

你想知道一个元素最终生效的样式值，包括来自样式表（而不是内联 style）的样式。

ID 选择器的优先级高于 class 选择器，所以背景色是蓝色。注意返回值是计算后的值：颜色统一变成 rgb(...) 格式，长度统一变成 px。

⚠ 谨慎使用 getComputedStyle

调用它会迫使浏览器立刻完成样式（有时还有布局）计算。在循环中反复「改样式 → 读计算样式 → 改样式」，会导致布局抖动（layout thrashing），严重拖慢页面。 需要读多个值时，先集中读完，再集中写。它返回的对象是「活的」，元素样式变化后读取到的值也会变。

小结

  • Custom Highlight API：Range 圈文字 → new Highlight() → CSS.highlights.set(名字, …) → ::highlight(名字) 写样式；不改 DOM，能跨元素。
  • Font Loading API：new FontFace() + document.fonts.add() + load()；document.fonts.ready 等待全部字体；多数情况 font-display 就够。
  • View Transitions：document.startViewTransition(更新DOM的回调)，用 ::view-transition-* 伪元素和 view-transition-name 定制动画；记得特性检测。
  • insertRule 动态加规则；改一个值用 CSS 变量；整套规则用可构造样式表。
  • classList.toggle(名, 条件) 按条件切换类；matchMedia 查询并监听媒体条件变化。
  • element.style 只有内联样式；getComputedStyle 是层叠后的最终值，注意性能。

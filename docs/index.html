为什么要学 Web API？

Web API 是浏览器暴露给 JavaScript 的一组全局对象和函数。你的代码通过它们操作页面（DOM）、发起网络请求、存储数据、调用摄像头和剪贴板…… JavaScript 语言本身只负责「计算」，真正让网页能做事的，是这些 API。

📦

更少的依赖

以前要靠 jQuery、Moment.js、Axios、各种 UI 库完成的事，今天很多已是浏览器内置能力。

⚡

更快的页面

原生 API 不占用下载体积，由浏览器用 C++ / Rust 实现，通常比 JS 库更快。

🔐

更低的风险

开源库可能停止维护，甚至被投毒；浏览器 API 由四大浏览器厂商长期维护。

♿

更好的无障碍

原生的 dialog、details、popover 自带键盘操作和屏幕阅读器语义，比手写组件更可靠。

Baseline 徽章

浏览器支持程度是使用 Web API 时最常见的顾虑。本教程统一采用 Baseline 口径标注（由 W3C WebDX 社区组制定，caniuse 与 MDN 均已采用）：

徽章含义建议
广泛可用在 Chrome、Edge、Firefox、Safari 的桌面与移动版本中都已支持超过 30 个月放心使用
Baseline 2025在该年份首次在上述所有浏览器的最新版本中可用面向较新浏览器的项目可以使用；需要兼容旧设备时准备降级
有限支持至少有一个主要浏览器尚未支持只作为渐进增强，必须特性检测并提供降级方案
已废弃规范已不推荐或浏览器已移除不要在新代码中使用

浏览器的发展速度很快，本教程中的支持信息以 2026 年为准。在正式项目中使用前，请到 caniuse.com 或 MDN 查看最新数据。
